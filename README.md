# Pac-Man

A neon-lit Pac-Man arcade game: guide Pac-Man through the maze, eat every pellet, and stay ahead of the ghosts — until a Power Pellet turns the hunter into the hunted.

## Two ways to play

| Version | File | How to run |
|---|---|---|
| Jupyter Notebook | `Pac-Man/Pac_Man-Game.ipynb` | Open in Jupyter / Google Colab and run the cells |
| Browser (HTML) | `Pac-Man/Pacman_Arcade.html` | Just open the file in any modern browser |

## Gameplay

- Eat all the pellets in the maze to score
- 3–4 ghosts chase Pac-Man through the maze
- Grab a **Power Pellet** to flip the chase — ghosts run, and eating them racks up bonus points
- Clear the maze without losing your lives to win
